# Tarea para Antigravity: buscar hackatones (noviembre 2026 a marzo 2027)

Buscá en la web hackatones y convocatorias con premio o créditos donde puedan entrar estos proyectos de Guillermo Siaira (participante individual, Argentina):

- **DORA**: agente con LLM que planifica una campaña agrícola; un motor de programación lineal calcula y un verificador bloquea todo número que no salga del motor. Pasó del 38 % al 97 % de respuestas correctas. Repo: github.com/GuillermoSiaira/dora-farm-agent.
- **El mismo núcleo para otros rubros**: finanzas de una pyme (SIG-Agent), logística, recursos humanos.
- **Registro on-chain**: el hash de cada simulación verificada se publica en una cadena de bloques y se compara después con lo que pasó, incluidos los errores (Arbitrum u otra).
- **Juegos educativos**: Invisible Hand (economía, IB y universidad) y un juego de matemática en diseño.
- **Investigación**: modelos de lenguaje más chicos y baratos con arquitecturas verificadas.
