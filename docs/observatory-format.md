# DORA Regional Observatory: Data Contract & Format

This document defines the schema and data contract for `observatory/latest.json` (and dated files in `observatory/<YYYY-MM-DD>.json`).

Frontends, static dashboards (such as `site/index.html` on Vercel), and custom UI tools can rely on this specification.

---

## 1. Top-Level Fields

| Field | Type | Description |
|---|---|---|
| `date` | `string` | Benchmark date in `YYYY-MM-DD` format (e.g., `"2026-10-27"`). |
| `timestamp` | `string` | ISO 8601 UTC timestamp of execution (e.g., `"2026-10-27T16:27:40.629647+00:00"`). |
| `regions` | `object` | Dictionary mapping region identifiers (e.g., `"southeast_buenos_aires"`) to their detailed regional analysis object. |
| `commentary` | `string \| null` | Verified market commentary generated by LLM if enabled, or `null`. |

---

## 2. Per-Region Fields (`regions[<region_key>]`)

Every region object in `regions` contains the following fields:

| Field | Type | Description |
|---|---|---|
| `key` | `string` | Canonical identifier for the region (e.g., `"southeast_buenos_aires"`, `"pampas_core"`, `"iowa"`, `"mato_grosso"`). |
| `name` | `string` | Display name of the region and locality (e.g., `"Southeast Buenos Aires (Balcarce)"`). |
| `placeholder` | `boolean` | `true` if any underlying data or land figures are provisional/estimated; `false` if verified against official publications. |
| `port` | `string` | Primary export terminal or port destination (e.g., `"Quequén"`, `"Up-River Rosario"`). |
| `distance_km` | `number` | Distance from representative farm to the port in kilometers. |
| `coords` | `[number, number]` | Coordinates `[latitude, longitude]` for interactive Leaflet mapping. |
| `freight_usd_t` | `number` | Freight tariff to port in USD per metric tonne. |
| `freight_source` | `string` | Citation or regulatory reference for the freight tariff. |
| `area_ha` | `number` | Benchmark farm area in hectares (default: `500.0`). |
| `land_price_usd_ha` | `number` | Benchmark market value of agricultural land in USD per hectare. |
| `land_source` | `string` | Cited source for the land valuation (e.g., CAIR, ISU survey, IMEA). |
| `npv_usd` | `number` | Net present value of season economic profit in USD. |
| `npv_per_ha` | `number` | NPV divided by total farm area (`USD/ha`). |
| `final_wealth_usd` | `number` | Total cash wealth at the end of the 15-month planning horizon (`USD`). |
| `capital_committed_usd` | `number` | Starting equity/capital committed by the producer (`USD`). |
| `return_on_capital` | `number` | Annualized rate of return on working capital committed (e.g., `0.5715`). |
| `return_on_capital_pct` | `number` | Annualized return on working capital expressed as a percentage (e.g., `57.15`). |
| `return_on_capital_and_land` | `number` | Annualized rate of return accounting for both operating capital and total land asset value. |
| `return_on_capital_and_land_pct` | `number` | Annualized return on capital and land expressed as a percentage (e.g., `1.60`). |
| `capital_shadow_price` | `number` | Dual variable of starting equity: present value gain per additional USD of own capital. |
| `scarce_fortnights` | `string[]` | List of fortnight labels where the internal shadow cost of funds exceeds the market benchmark interest rate. |
| `land_shadow_price_usd_ha` | `number` | Dual variable of farmland constraint: marginal value of an additional hectare in USD/ha. |
| `storage_shadow_price_usd_t` | `number` | Total dual value of on-farm storage capacity across the entire season in USD/tonne. |
| `crop_mix` | `object` | Mapping of crop name to optimal hectares allocated (e.g., `{"wheat": 58.9, "soybean": 250.0}`). |
| `crop_shares` | `object` | Mapping of crop name to fraction of total farm area allocated (e.g., `{"soybean": 0.50}`). |
| `price_source` | `string` | Description of price source and snapshot date. |
| `price_curve_metadata` | `object` | Metadata including `source`, `as_of`, and `placeholder` status of futures/spot curves. |
| `internal_rates` | `object[]` | Fortnight-by-fortnight internal rate of return (`rate_annual`), fortnight index (`fortnight`), and calendar month (`month`). |
