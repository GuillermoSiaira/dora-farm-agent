Es un aporte de nicho: mostrar cómo usar bien la programación lineal sin depender de la API de los grandes proveedores, para empresas que cuidan sus datos. Los modelos grandes se siguen usando para investigar y comparar. Detalle: docs/plan/foco-2026-11.md.
